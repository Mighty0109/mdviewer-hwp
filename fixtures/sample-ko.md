# 한글 마크다운 읽기 예제

MDViewer에서 **한글 문서**와 다양한 블록을 읽습니다. 검색어는 `자동 새로고침`입니다.

## 표와 코드

| 항목 | 확인할 내용 |
| --- | --- |
| 제목 | 한글과 목차 |
| 파일 감시 | 자동 새로고침 |
| 이미지 | 문서 기준 상대 경로 |

```rust
fn main() {
    println!("안녕하세요, MDViewer!");
}
```

### 체크리스트

- [ ] 외부 편집 후 자동 새로고침 확인
- [x] 한글 제목과 표, 코드 읽기
